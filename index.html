01 — À propos

Le backend au centre, le produit en tête

Je conçois les API, les données et les architectures qui font tourner les applications métier.

Je suis développeur backend / fullstack, spécialisé en PHP (Symfony, Laravel) et Node.js (NestJS). J'accompagne les entreprises dans la conception, le développement et la maintenance de leurs applications métier, API et services.

Mon expérience couvre des contextes variés : CRM, e-commerce, refonte en microservices, back-offices et intégration de services tiers. J'aime comprendre le besoin métier, modéliser les données proprement, puis livrer des solutions maintenables et testées.

Je reste à l'aise côté front-end (Vue.js, React.js) pour intégrer les interfaces et livrer une fonctionnalité de bout en bout — mais mon terrain de jeu principal reste le back-end : API REST ou gRPC, données et performance.

  • API REST, gRPC & architectures microservices
  • Modélisation & optimisation des données
  • Applications métier, CRM & back-offices
  • Tests, maintenance & évolution d'applications
